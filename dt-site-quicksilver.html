The loop

01Measure

Times your app's most-hit endpoints and pages. Before numbers on record.

02Diagnose

Finds the single biggest bottleneck with evidence: query plans, logs, waterfalls. Never vibes.

03Fix

Builds the smallest safe fix. Production changes always need your yes.

04Prove

Re-measures the exact same targets and hands you the before and after table.

House rules

  • One bottleneck per run. No whack-a-mole.
  • Never deploy to production without a human yes.
  • Never report an improvement it didn't measure.
  • If the fix wins less than 10%, it says so and reverts.

Works with the agent you already use

QuickSilver ships as a plain prompt plus a script kit. Any agent that can run shell commands can run it: Claude Code, Codex, Cursor, Hermes, or plain cron.
